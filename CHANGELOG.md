# Changelog

Every notable change, newest first. Versions follow [Semantic Versioning](https://semver.org): a
raised component resets the ones to its right (0.1.24 → 0.2.0 → 1.0.0). Sections are generated by
`deno task release` from the [Conventional Commits](https://www.conventionalcommits.org) since the
previous version; stable versions are cut on `release`, betas (`X.Y.Z-beta.N`) on `beta`.

## [0.1.0] - 2026-10-06

The first numbered version: the state of the project when versioning started. It covers:

- profiles for Claude Code and Claude Desktop, isolated on one machine, launched by one bash launcher;
- the local console on `127.0.0.1:7331` (today, tasks, brain, connections, system) and the PySide6 tray app;
- the brain, a multi-account memory and task service with an MCP endpoint, and the public site;
- the MCP registry with per-account servers and the encrypted secret vault;
- `claude-multi doctor`, `install`, `update` and the rest of the CLI;
- one quality gate for CI and the pre-push hook (`scripts/ci.sh`), guard hooks that decide without
  `jq`, and the release tooling that writes this file.
