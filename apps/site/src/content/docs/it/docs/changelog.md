Le note di rilascio si scrivono una volta sola, in inglese, e non vengono
tradotte. Le trovi, versione per versione e dalla più recente, nel
[changelog](/docs/changelog/) in inglese.

La console mostra le stesse note dopo un aggiornamento, sotto **What's new**.
